# Asset provenance

The current landing page uses the original project's public media and full wordmark font. No private customer records, database exports, or credentials were copied.

- `public/hero-poster.webp`: original legacy poster.
- `public/media/hero-{1080-av1,720-avc,480-av1,480-avc}.mp4`: re-encodes (no audio) of the original HEVC video at `danirusev-assets@main/opt/hero/hero.mp4` (12.85 MB, not playable in Firefox or most Chrome installs). 8-bit AV1 first, H.264 fallback; screens up to 767px get 480p (1.7 MB), larger ones 1080p AV1 (6.2 MB). Re-encode from the original when it changes.
- `public/hero-poster-{640,1080}w.webp`: downscaled copies of `hero-poster.webp` for the poster `srcSet`.
- `public/fonts/Gagalin-Regular.otf`: full original Gagalin font, kept as the master. Pages load `gagalin-latin.woff2` (Basic Latin, all layout features, 53 KB; the wordmark only uses these characters, so it is preloaded) and `gagalin-full.woff2` (the whole font losslessly repackaged as WOFF2, 116 KB) through `unicode-range`, so any other character still renders in the full face. Regenerate both with fontTools (`pyftsubset … --unicodes=U+0020-007E,U+00A0 --layout-features='*' --flavor=woff2`).
- `public/media/*-{480,960,1600}w.webp`: responsive widths generated by `pnpm --filter @danirusev/web optimize:media` (needs ffmpeg with libwebp) and listed in `src/features/landing/media-variants.json`; `<Image>` turns them into `srcSet`. Masters wider than 1920px (the 4783×7174 driver portrait) are never served. Run the script after adding media.
- `public/apple-touch-icon.png`, `public/icon-*.png`: the DR11 wordmark in Gagalin on the site background, rendered for the web app manifest.
- `public/media/*`: local copies of feature, experience, portrait, testimonial, and YouTube images. `src/features/landing/media-manifest.json` records every original URL and its local filename.
- `public/favicon.ico`, `public/og-image.jpg`: legacy public assets.
- Icons use the legacy lucide-react 0.517.0 set. The small local brand-icon definitions retain its ISC attribution.
- `public/fonts/geist-mono-latin.woff2`: the latin subset of Geist Mono served by danirusev.com (`/_next/static/media/f5271587012faf78-s.p.woff2`, captured 2026-10-27). It renders the experience page's program-time pills (`font-mono`), as on the reference. Geist is licensed under the SIL Open Font License 1.1 (Vercel).
- Experience detail galleries are not copied locally: they load the image URLs the catalog returns (Echoray media in live mode, the `danirusev-assets` PNG masters named in the fixture product files otherwise).
- `public/partnership/*`: assets for the private `/partnership` sponsor page. Photos are WebP crops of `danirusev-assets` originals and of Dani's own presentation photos (rally Suzuki, Vivacom × SkyShowtime day, D2 set, paddock, Red Bull drift), resized and cropped with ImageMagick to two widths each (`-800`/`-1600`, `-600`/`-1200` for 4:5, `-480`/`-960` for cards, quality 55–72). `gen-livery-mockup` is an AI-generated livery illustration, captioned „Концептуална визуализация“; it does not depict Dani's car. The cover reuses the landing hero video and poster. `balkan-drive-logo.webp` is the show's logo supplied by Dani. The marquee fonts in `public/fonts/partnership/` (Russo One, Rubik Glitch, Stalinist One, Tektur; SIL OFL 1.1) are Google Fonts `text=` subsets containing only their single word. Vivacom, SkyShowtime and D2 logos come from the brands' official sites (trademarks, no open license); `og.jpg` was rendered from a generated dusk-stage image kept outside the repository. Sources and the unverified-claims list are in the git-ignored `output/partnership/research.md` from 2026-10-30.
- Body/nav/headings use the deployed reference's system sans-serif stack. Inter and the separate Geist Black font introduced by the first scaffold were removed.

The source media repository is [Ethereumistic/danirusev-assets](https://github.com/Ethereumistic/danirusev-assets). YouTube thumbnail and channel-avatar URLs come from the published landing-page snapshot on 2026-10-27. Media is served locally; no YouTube feed or CMS is called at runtime.
